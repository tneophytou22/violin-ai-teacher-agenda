# Violin AI Curriculum Modules

This directory is the canonical home for curriculum data used by the Teacher Agenda.

## Rules
- Curriculum data is teacher-facing.
- Existing student data remains backward-compatible with `VIOLIN_AI_AGENDA_V10`.
- Scale & Arpeggio Curriculum V1 is maintained separately from UI code.
- Future modules should be added as independent files rather than enlarging `index.html`.
- No curriculum module may silently alter the live `main` application.
